# Axis

## Project Overview

Axis is an AI-driven workplace assistant designed to help professionals improve productivity and workflow efficiency. The platform provides intelligent tools for email generation, task planning, chatbot assistance, and meeting note summarization.

## Features

* Smart AI email generator
* AI task planner
* Conversational AI chatbot
* Meeting notes summarizer
* Clean and professional user interface

Chatgpt
